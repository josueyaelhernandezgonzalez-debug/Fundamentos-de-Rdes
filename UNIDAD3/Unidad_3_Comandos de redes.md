- ping: 
 nos sirve para verificar que exista una conexión ya sea por medio de interned, web o red local. También podemos medir la latencia donde mide un tiempo exacto de lo que tarda en mandar un mensaje y si hay perdida de datos. 

- ipconfig:
Nos sirve para ver la configuración de la red de nuestro dispositivo y administra direcciones ip asignadas por el modem o router.
- variantes
- ipconfig /all: 
sirve para mostrar la dirección MAC de nuestro dispositivo como mensaje de origen como también muestra información detallada de cada adaptador de red.
- ipconfig /release:
soluciona un error de conexión de red ya que serve para liberar la dirección ip actual.
- ipconfig /renew:
solicita una dirección ip nueva al router (se utiliza después de /release).
- ipconfig /flushdns:
sirve para borrar la cache del DNS  de la computadora
- tracert:
nos sirve para que muestre el camino y salto por los que pasa los datos y identificar don de hay un fallo 
- cd:
este comando nos permite entrar a la configuración de varias acciones ya que esta para abrir archivos desde el CMD en ves de usar el cursor 

- cd Documentos:
entra a la carpeta Documentos
- cd ..:
sirve para darle un nivel en la jerarquía de carpetas
- cd \ :
sirve para llevarte a la raíz del disco duro
- cd ~ :
es para llevarte al directoria del usuario actual
- dir:
muestra una lista de los archivos y carpetas que se encuentran en el directorio actual donde estas posicionado, se pude acceder para ver el contenido de una carpeta
